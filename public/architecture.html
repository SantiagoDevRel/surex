SureX

A trust registry for MCP servers, and a gate that reads it. Nothing checks the servers your agent runs today — SureX puts one conscious decision in front of a flagged one, and stays silent otherwise.

Two loops · one shared record Arkiv decides · Walrus proves
Plate A

The Gate

consumer loop · runs on EVERY tool call · budget: milliseconds

A PreToolUse hook fires before Claude Code executes any MCP tool. It identifies the server from the install config alone — never by running it — and resolves one of three outcomes. In the overwhelming majority of calls, the outcome is silence.

Every block is overridable in one command, printed inside the block itself. A block a user cannot pass is a block that gets the whole gate uninstalled the first time it is wrong. The job is to make sure nobody runs a flagged server without knowing — not to take the decision away from them.

A block never says “unsafe”. It says what was reviewed, when, by which model and prompt version, that no human audited it, what the code can reach, and whether anyone is contesting it. Then it hands the decision back.

Plate B

The Registry

supply loop · runs on submission and on every release · budget: minutes

How entries get there. Three inlets, one licence gate, one review, two records. The code and the judgement about the code are stored as separate content-addressed blobs, so each can be verified without the other — and a verdict can be superseded without touching the evidence it was made against.

Arkiv answers “what is the state of this server?” Walrus answers “show me exactly what was said, and prove it has not changed.” That split is a hard rule, not a preference: the gate sits in front of every tool call, so every decision-critical field is an Arkiv annotation resolvable in one query. The evidence body is fetched from Walrus at exactly one moment — when SureX is about to block and a person is about to read it.

Nothing is overwritten. Source records and review records are immutable and append-only; a small mutable head carries current state. A correction supersedes a verdict, and is as durable and as prominent as the original claim.
