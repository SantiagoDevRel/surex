THE PROBLEM, IN THREE LINES
AI assistants can be handed plug-ins that do real things — read your files, send your email, query your database.
These plug-ins are called MCP servers. Anyone can publish one — and once added, it runs with every permission your assistant has.
Nothing checks it first.
CASE FILE · A REAL INCIDENT
One package behaved perfectly for fifteen versions. In the sixteenth, it quietly began copying every outgoing email to a stranger.
It ran for weeks.

what happens when someone says the verdict is wrong
open to anyone — people and AI agents alike
CONTEST
Anyone can contest a verdict
A person — or an autonomous AI agent that depends on the plug-in and has a real stake in it not being wrongly flagged.

ON THE RECORD

UNCHANGED

UNDERNEATH

Three technologies, three jobs

the third question is the one that matters
ARKIV · THE INDEX
WHAT IS IT?
A searchable index built for instant answers.
WHAT DOES IT DO HERE?
Answers "what is the state of this plug-in right now?" fast enough to run before every single action.
WHAT IF YOU REMOVED IT?
The check becomes too slow to sit in the path of every action — so it would simply be skipped.
"It answers 'what do we know about this plug-in?' before you finish blinking."
WALRUS, ON SUI · THE RECORD STORE
WHAT IS IT?
Tamper-evident storage where every record's address is derived from its exact contents.
WHAT DOES IT DO HERE?
Holds every sealed copy of code and every sealed verdict. Change a single byte and the address no longer matches — the swap is obvious to everyone.
WHAT IF YOU REMOVED IT?
You'd have to trust whoever runs the registry — which defeats the entire point of a registry.
"Change one byte of the evidence, and everyone can see the seal is broken."
WORLD · THE HUMAN BEHIND EACH APPEAL
WHAT IS IT?
A way to prove a real, unique human is present — without saying who they are.
WHAT DOES IT DO HERE?
Every contest — even one filed by an AI agent — must have one real human standing behind it.
WHAT IF YOU REMOVED IT?
Anyone could flood the appeals process with thousands of fake objections — and real ones would drown.
"Every appeal has one real human behind it — no matter who files it."
READ THIS BEFORE YOU TRUST IT — WHAT THE SYSTEM DOES NOT CLAIM
1 · The review is done by an AI model. No human audited it.
2 · "Reviewed" means: what the code appeared to do when it was read — not that the plug-in is safe.
3 · It cannot always prove that the code reviewed is the exact code now on your machine.
The system says reviewed — never safe, trusted, verified or secure.
